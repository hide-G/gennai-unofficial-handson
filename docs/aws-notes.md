## 資格情報の取り扱い

- アクセスキー、シークレット、トークンなどをコマンドや原稿、ログ、コミット履歴に含めない
- 環境変数、AWS CLI プロファイル、AWS SSO などの安全な仕組みを使う
- 万が一漏えいした場合は速やかにキーを無効化・ローテーションする
