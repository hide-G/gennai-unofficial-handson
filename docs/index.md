# 概要

本サイトは、ガバメントAI「源内」を自分の環境にデプロイして試すための、非公式ハンズオン資料です。

!!! warning "免責"
    本資料は有志により作成された非公式の学習資料です。デジタル庁および「源内」の公式提供者が作成・承認・サポートするものではありません。内容は利用者自身の責任で確認してください。

## 対象プロジェクト

本ハンズオンで扱う対象は次の2つです。

- [源内 Web](https://github.com/digital-go-jp/genai-web)
- [源内 AI アプリ](https://github.com/digital-go-jp/genai-ai-api)

## このサイトの目的

- 「源内」を実際にデプロイしてみたい有志が、手を動かして理解を深めるための手順を集める
- 公式リポジトリのREADMEを補足する形で、つまずきやすい箇所や注意点を共有する
- 学習後のリソース削除まで含めて、安全に試せる流れを提供する

## 章立て（予定）

現在は概要ページのみを公開しています。以下は今後追加予定の章立ての案です。順序や粒度は執筆しながら調整します。

- [ ] 事前準備（GitHubアカウント、AWSアカウント、必要ツール）
- [ ] AWSアカウントの注意（コスト、権限、リージョン、切り分け）
- [ ] 源内 Web のデプロイ
- [ ] 源内 AI アプリのデプロイ
- [ ] 動作確認と組み合わせ
- [ ] 後片付け（リソース削除、コスト確認）
- [ ] 想定質問集（FAQ）
- [ ] 用語集・参考リンク

!!! info "章立ての追加について"
    章の追加や並び替えは、`docs/` 配下にMarkdownを追加し、`mkdocs.yml` の `nav` に登録するだけで反映されます。GitHub Actionsにより、`main` ブランチへのマージ後にGitHub Pagesが自動更新されます。

## サイトの使い方

- 上部の検索欄からキーワード検索ができます
- コードブロックの右上のアイコンを押すと、ブロック全体をクリップボードへコピーできます
- ナビゲーションの **A4印刷 / PDF保存** を開き、ブラウザーの印刷メニューからA4縦・PDF保存を選択すると、全ページをまとめたPDFを保存できます
- ライトモードとダークモードは、ヘッダー右上のアイコンから切り替えできます
