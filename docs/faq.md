# 第8章 想定質問集（FAQ）

!!! info "この章の状態"
    現時点では章立てのみを用意しています。質問と回答は今後追加します。

## 想定される質問カテゴリ

- 前提・環境について
- デプロイ手順の失敗時の対応
- 動作確認・トラブルシュート
- コスト・後片付け
- セキュリティ・秘密情報の取り扱い

## 質問の追加方法

- 実施中に遭遇したつまずきは、Issue として起票していただけると助かります
- 一般化できる内容はこの章に追記していきます

!!! info "Issueと Pull Requestについて"
    Issueは誰でも起票できます。Pull Requestを送っていただく場合は、非公式資料である旨と、記載内容の正確性について執筆者側で確認する必要があるため、レビューを経てからのマージになります。
